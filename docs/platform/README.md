## Convenções

- **Requisito:** necessidade expressa pelo usuário; não comprova ausência no upstream.
- **Proposta:** sugestão técnica ainda não aprovada como implementação definitiva.
- **A verificar:** comportamento que exige inspeção do código ou documentação upstream.
- ADRs têm estado explícito. Uma proposta não deve ser tratada como decisão aceita.
- Novas lembranças sobre limitações entram no backlog, vinculadas aos requisitos.
- Não guardar senhas, tokens, chaves ou sessões reais nestes documentos.
